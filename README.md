# AKA.GROUP — сайт недвижимости

Статический адаптивный сайт на HTML/CSS. Не требует сборки и установки зависимостей.

## Как открыть локально
Откройте `index.html` в браузере.

## Как загрузить на GitHub
1. Создайте новый публичный или приватный репозиторий на GitHub.
2. Нажмите **Add file → Upload files**.
3. Загрузите `index.html`, папку `assets` и этот `README.md` (можно загрузить ZIP и распаковать перед загрузкой).
4. Для публикации откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
6. Через некоторое время GitHub Pages покажет адрес опубликованного сайта.

## Что внутри
- `index.html` — вся вёрстка, стили и контент.
- `assets/` — предоставленные фото и видео.
- Контакты и ссылки на предложения уже добавлены.

## Важно
Ипотечные цифры взяты из предоставленного рекламного изображения и требуют подтверждения перед публикацией. Названия и описания разделов о комплексе — презентационные тексты, не официальные характеристики застройщика.
