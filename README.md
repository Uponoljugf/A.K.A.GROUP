# AKA GROUP — сайт для GitHub Pages

## Публикация
1. Создайте публичный репозиторий на GitHub.
2. Распакуйте архив и загрузите **всё содержимое папки** `aka_group_site` в корень репозитория: `index.html`, `README.md` и папку `assets`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`, ветку `main` и папку `/(root)`, затем Save.
5. После публикации сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Видео перекодированы в MP4 (H.264) и подключены локально из папки `assets`, чтобы браузер мог воспроизводить их с GitHub Pages.
